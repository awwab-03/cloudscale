# Phase 7 — Cognito and EC2 IAM role

## Inception

### Goal (plain language)
Give the app a way for students to sign up and sign in (Cognito), and give the app servers a role that lets them use only the AWS resources they need, nothing more.

### Requirements
- **Cognito user pool** `cloudscale-users`: sign-in with email, email verification on sign-up, sensible password policy.
- **App client** without a secret, with only `ALLOW_USER_PASSWORD_AUTH` and `ALLOW_REFRESH_TOKEN_AUTH` (Flask calls SignUp / ConfirmSignUp / InitiateAuth server-side and checks the ID token against the pool's JWKS).
- **SSM SecureString** `/cloudscale/app-secret-key` (Flask session key), generated by Terraform, never written to a file or Git.
- **CloudWatch log group** `/cloudscale/app` (7-day retention) so the log permission can be scoped to it.
- **IAM role `cloudscale-ec2-app` + instance profile**, trust only `ec2.amazonaws.com`, with:
  - S3: `GetObject` on `artifacts/app/*`; `Put/Get/DeleteObject` on `uploads/originals/*`; `GetObject` on `uploads/thumbnails/*` and `uploads/meta/*`
  - Secrets Manager: `GetSecretValue` on the RDS secret ARN only
  - SSM: `GetParameter`/`GetParameters` on `/cloudscale/*` only; `kms:Decrypt` limited by `kms:ViaService = ssm.us-east-1.amazonaws.com`
  - SNS: `Publish` and `Subscribe` on the `claim-notifications` topic ARN
  - Bedrock: `InvokeModel` on the Nova Micro inference profile and its foundation-model ARNs
  - SageMaker: `InvokeEndpoint` on the `cloudscale-category` endpoint ARN
  - CloudWatch Logs: `CreateLogStream`/`PutLogEvents` on `/cloudscale/app` only
  - AWS-managed `AmazonSSMManagedInstanceCore` (Session Manager)
- No `AdministratorAccess`, no wildcard actions. Every `*` resource is documented in `docs/iam-justification.md`.
- Tag `Project=CloudScale`.

### Acceptance criteria
- `terraform plan` shows only Cognito, SSM, log group, and IAM resources.
- After apply: a test user can sign up and confirm via the CLI; the role's policy has no `*` action and the only `*` resource is the KMS statement with its ViaService condition.

### Notes / risks
- Some ARNs refer to resources created in later bolts (SNS topic, SageMaker endpoint). I construct them from fixed names (`claim-notifications`, `cloudscale-category`), and those later bolts must use exactly those names.
- Bedrock `Converse` needs `bedrock:InvokeModel`. The `us.` inference profile can route to us-east-1, us-east-2 or us-west-2, so the foundation-model ARNs for those three regions are allowed.
- The generated secret key is stored in Terraform state, which is local and gitignored.
- Cognito's built-in email sender is limited to about 50 emails/day, which is enough for the demo.
- Cost: Cognito (first 10,000 MAU free), SSM standard parameter, log group, IAM: effectively $0.
- `cognito-idp:AdminGetUser` is not granted, because the app does not need it. It will be added only if used.
